# HoloBeat

HoloBeat is a neural network that automatically plays the rhythm fishing game in [Holocure - Save the Fans!](https://store.steampowered.com/app/2420510/).

## Project Structure

- `src/`: Source code.
- `data/`: Data used by the project.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/paleya/HoloBeat.git
cd HoloBeat
```

## Running

Before running the program, position your character as shown below next to the fishing area.

<img width="398" height="402" alt="image" src="https://github.com/user-attachments/assets/23ea9a1f-c9f8-4bc5-9543-61765b9acd4f" />

Run `Main.java` and switch back to the game. A demo of this in action can be found at https://youtu.be/I4FcafMa1QE.
